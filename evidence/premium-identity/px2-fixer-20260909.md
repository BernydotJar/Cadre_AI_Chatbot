## Retained failures and repairs

The first full Playwright run after moving the composer passed 48/52. Two defects reproduced in both projects:

1. Reset focus was lost because the old composer received focus before React remounted it in the empty-state position. The repair tracks the prior `started` state and restores focus after either user-driven composer relocation without auto-focusing first paint.
2. The 360x640 text-spacing check exposed a sub-pixel fold boundary. The user turn, then the privacy note, landed less than one CSS pixel outside the viewport after `scrollIntoViewIfNeeded`. The mobile layout now uses an integer 38px display size at <=430px and an 11px section gap, preserving full viewport visibility without weakening the ratio-1 assertion.

Focused regression then passed, followed by the complete browser matrix.
