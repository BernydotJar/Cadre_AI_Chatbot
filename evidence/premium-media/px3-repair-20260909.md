# PX3 repair evidence — perceptible restrained motion — 2026-09-09

Independent Claude Code critic `evidence/premium-critic/claude-px3-media-critic-20260909.md` returned CHANGES_REQUESTED on the first ambient loop. The review measured the original frames as effectively static and warned that merely amplifying the original radial/glow content would reintroduce the cyberpunk register rejected in PX2.

## Repairs

1. **Perceptible, flat motion instead of glow**
   - Regenerated the 8s local clip with flat architectural planes moving on sinusoidal paths: one restrained burgundy plane, one low-opacity warm-neutral plane and one fine horizontal guide line over a dark field.
   - No radial arc, bloom, neon edge, embedded text, footage, faces, or audio.
   - New sampled-frame ImageMagick MAE is 1.09%–1.74% across quarter-cycle samples instead of the critic's ~0.10%–0.26% contact-sheet deltas. The 0.5s vs 7.9s seam delta is 0.67%, supporting a quiet loop transition.
   - New media remains small: 105,727-byte H.264 video + 3,630-byte WebP poster.

2. **Binary contract guard**
   - `tests/product/media-assets.test.ts` pins the exact reviewed video/poster SHA-256 and byte sizes with explicit payload budgets.
   - The fresh ffprobe artifact proves the pinned video is 8.000s, 1280x720/24fps and contains one video stream with no audio stream. Any binary drift now breaks deterministic tests until evidence and hashes are deliberately refreshed.

3. **Pause/stop control**
   - Motion-enabled users receive a visible 44px-high Pause/Play control with an accessible name and pressed state.
   - Reduced-motion users receive only the poster and no motion control/video element.
   - The first full browser run after adding the control passed 55/56; the mobile control sat behind the compact hero text because it was trapped in the media stacking container. The repair renders the button as a direct positioned child of the hero, above copy, while the media remains z-index 0 and pointer-inert.

4. **Mobile evidence**
   - Dedicated live geometry now covers 1440x1000, 360x640 and 320x568 motion plus desktop/mobile reduced-motion cases.
   - All samples report no horizontal overflow. The 320/360 Pause control is 75.625x44 CSS px and remains within the hero. Reduced-motion samples mount zero videos and zero controls.
